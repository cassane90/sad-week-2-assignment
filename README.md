# SAD Week 2 Assignment

This repository contains two Systems Analysis and Design exercises.

## 1. Legacy Healthcare Portal Modernization

### Bounded Contexts

1. **Patient Management**
   - Patient
   - Appointment
2. **Billing & Insurance Claims**
   - Invoice
   - Payment
   - Insurance Claim
3. **Lab Test Diagnostics**
   - Lab Test
   - Lab Result

## 2. Campus Safe Ride System

A simple university service that allows students to request a safe ride between campus locations at night.

### Bounded Contexts

1. **Student Management**
   - Student
   - Student Account
2. **Ride Management**
   - Ride Request
   - Pickup Location
   - Destination
3. **Driver & Vehicle Management**
   - Driver
   - Vehicle
